# 業務別ページの図解改修

基準コミット: f047bb2c18f03755dfffe63a8d469117c5355521
参考: https://lorenics.com/ai.html
工程や情報の所在を図解し、具体的な成果物を示す方法を参考にした。文章・図版はIDM用に制作。参考サイトの実績数値や画像は転用していない。

- 商談：会話の分類図、担当者と期限を持つ商談メモ、次回への時間軸。
- 提案：顧客の課題と提案の対応図、4枚の提案書見本、文章の検証例。
- 引き継ぎ：役割別の情報伝達、設備工事の引き継ぎ票、確認担当表。
- 業務：店舗対応の判断分岐、3場面の切り替え、経験者と新人の役割。
- 振り返り：改善循環、保守サービスの振り返りボード、請求確定の確認。

共通のBefore/Afterと3ステップ構成を撤去。ホームの5カードは専用SVGへ。会議写真は商談ページのみ、パソコン写真はトップのみ。説明例は架空である旨を明記。既存のグリーン、明朝見出し、余白と導線を継承。

- 店舗対応3ボタンの内容とaria-pressed切り替えを確認。
